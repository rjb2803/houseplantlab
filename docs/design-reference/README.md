# Approved design reference

`approved-interface-reference.png` is the supplied visual direction for HouseplantLab.

The first implementation slice covers the shared header and the homepage at desktop and mobile widths. Plant photography shown in the reference is directional only: production pages must use properly licensed or original HouseplantLab photography and must not imply that temporary imagery is original evidence.

## Visual acceptance points

- Compact white header and dark-green HouseplantLab identity.
- Deep botanical-green, photography-led homepage hero.
- Cream and white section rhythm with restrained borders and shadows.
- Editorial serif display headings paired with compact sans-serif interface copy.
- Six-card popular-plants row on desktop and horizontal cards on mobile.
- Prominent diagnosis callout followed by a four-card article grid.
- Mobile hero retains the search action and three evidence/value points.

The remaining reference screens will be implemented in later slices using the same tokens and components.
